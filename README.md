# organize_downloads.bat

- A simple Windows batch script to automatically organize your Downloads folder by file type.  
This script moves files into categorized subfolders like Images, Documents, Videos, Music, Compressed, Scripts, and more.

- Un sencillo script batch para Windows que organiza automáticamente tu carpeta de Descargas según el tipo de archivo.  
Este script mueve los archivos a subcarpetas categorizadas como Imágenes, Documentos, Vídeos, Música, Comprimidos, Scripts, y más.

## Categories / Categorías

- Images / Imágenes: jpg, jpeg, png, gif, bmp, webp  
- Videos / Vídeos: mp4, mkv, avi, mov, wmv  
- Music / Música: mp3, wav, flac, aac, ogg  
- Documents / Documentos: pdf, doc, docx, xls, xlsx, ppt, pptx, txt  
- Compressed / Comprimidos: zip, rar, 7z, tar, gz  
- ISOs: iso, img  
- Executables / Ejecutables: exe, msi  
- Scripts: bat, cmd, ps1, sh  
- Others / Otros: todos los demás archivos
